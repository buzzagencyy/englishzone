# Purpose

The Teacher Portal is the teacher's daily workspace.

Everything a teacher needs should exist inside one dashboard.

The teacher should never need external spreadsheets, WhatsApp groups or manual tracking.

The portal should reduce administrative work and allow teachers to focus on teaching.
