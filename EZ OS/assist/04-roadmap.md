# Development Roadmap

Version: 1.0

Status: Official

Owner: English Zone Academy

Last Updated: July 2026

---

# Purpose

This roadmap defines the official development order of the project.

Every feature must be developed according to this roadmap.

No milestone should be skipped.

---

# Development Strategy

The project will be built in multiple phases.

Each phase must be completed, tested and approved before moving to the next phase.

Every phase should leave the project in a stable and deployable state.
